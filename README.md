# WWDC Video Ops — 即時投稿ランブック

Apple WWDC / iPhone 発表会などのリアルイベントで、動画（ロング・ショート）を
**素早く投稿する**ためのチーム用オペレーションシステム。
スプレッドシートの「思想」（時刻基準のランブック＋2階層タスク＋担当＋目標/実績＋チェック）を
ベースに、Webアプリ化したものです。

## 使い方
`index.html` をブラウザで開くだけ。サーバ不要・インストール不要。PC / スマホ対応。

1. ヘッダーで **イベント名** と **基準時刻(0:00)** を設定（「今」ボタンでイベント開始＝今に設定）
2. 以降、各ステップの **目標(開始+所要)** とのズレが自動で色表示・カウントダウンされる
3. タスクを進めたら **チェック / 開始 / 完了** をクリック（実績が自動記録）
4. トラブル時は **異常** ボタン → 復旧手順パネルと上部バナーに即表示

## 実装した5つの要望
- **Waterfall**：ステップを基準時刻順に縦のタイムラインで配置。同時刻のステップは横並び＝並行作業。
- **依存関係を矢印で**：カード下の「依存元」で前工程を選ぶと、カード間に矢印（フローチャート）を描画。状態に応じて色（通常/完了=緑/異常=赤点線）。
- **異常時フローへ遷移しやすく**：各カードの「異常」ボタン1クリックで赤表示＋復旧手順を展開。上部に「要対応（異常/遅延）」バナーが出て、ジャンプして対応できる。遅延（目標超過）も自動検知。
- **入力しやすく**：チェックボックス・インライン編集・台本のワンタッチ「コピー」・URL自動リンク・「＋サブタスク/＋ステップ」。
- **シンプルで見やすい**：システムフォント、明るい配色、レスポンシブ。

## リアルタイム同期（Firebase）
チームで同時に編集・チェックが反映されます。

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクト作成
2. **Realtime Database** を作成（テスト用ルールでまず動作確認 → 本番は認証付きルール推奨）
3. プロジェクト設定 →「マイアプリ」でウェブアプリを追加し、`firebaseConfig` をコピー
4. アプリ右上の **同期チップ**（未接続）をクリック → 設定JSONを貼付 → **ルームID**（例 `wwdc26`）を入力 → 接続
5. チーム全員が同じ `firebaseConfig` と **同じルームID** で接続すれば同期完了

- 最初に接続した人の内容が共有され、以後は全員で共同編集（最新の変更を反映 / Last-Write-Wins）。
- Firebase設定はブラウザに保存され、次回以降は自動接続。
- 未接続でもローカル（localStorage）で通常どおり使えます。

> セキュリティ: `firebaseConfig` は公開前提の値です。アクセス制御は Realtime Database の
> **セキュリティルール**で行ってください（公開イベント運用では認証必須を推奨）。

## カリフォルニア時刻
Appleイベントは現地（クパチーノ / 太平洋時間）基準のため、ヘッダーに
**🍎 Cupertino (PT)** の現在時刻を常時表示（夏時間も自動）。現地時刻・経過時間と並べて確認できます。

## データの保存・共有（オフライン手段）
- 入力はブラウザ内（localStorage）に自動保存。
- 同期を使わない場合は **書出(JSON)** → 共有 → **読込** でも共有可能。
- **初期化** でCSVベースのテンプレートに戻せる。
